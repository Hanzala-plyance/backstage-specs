# Backstage 0.2.0 desktop development candidate

Status: **not qualified for stable release**. Feature: `web-desktop-foundation`.
Runtime: Electron / React / TypeScript / Vite / Three.js / browser audio.

## Implemented

Native desktop shell; offline original practice track; shared MIDI/audio library;
single-player five-lane guitar/bass/rhythm/drum charts; tap and fret/strum input;
audio-driven timing, scoring, pause and results; online audio/community chart
search; local audio and YouTube conversion queue; persistent history/install retry;
button and signed-axis gamepad mapping; live input monitor; keyboard and MIDI drums.

Conversion remains an optional Python/FFmpeg service started lazily. Unity,
Python environments, model weights and user songs are excluded from the package.

## Evidence

- 47 Python converter/library regression tests passed.
- 25 desktop core/boundary tests passed, including tempo maps, scoring boundaries,
  input normalization, linked-path refusal, and persistent queue recovery.
- Five promotion-policy tests passed with explicit runtime selection.
- Electron smoke passed with real original practice audio, a keyboard score,
  frozen playback on pause, remapped simulated gamepad and disconnect pause.
  The app also earned two Star Power phrases, activated a 2x multiplier, retained
  playback speed 1.0 and scored the next note at double value.
- Live metadata search returned nine YouTube results and ten Chorus Encore results.
  No provider music was downloaded by this check.
- A generated eight-second original recording passed real upload, conversion,
  atomic installation and desktop MIDI load (16 expert chords).
- Initial Apple Silicon macOS package: approximately 291 MB total; application ASAR
  approximately 2.2 MB plus preparation source approximately 228 KB. Most size is
  Electron. These are disk measurements, not a claim about RAM or native performance.

## Remaining acceptance

No physical guitar/gamepad/MIDI hardware or audible latency was verified. Full YARG
parity is not implemented: advanced trill/tremolo lane forgiveness, big rock endings,
engine presets/dynamic windows, exact sustain-burst rounding, mixed open chords,
vocals, six-fret charts, .chart parsing, split stems, multiplayer and native Xbox
Riffmaster bridging remain excluded. Guitar scoring, HOPO/tap, open notes, scored
sustains, solo bonuses, phrase Star Power and whammy are implemented and unit tested.
Package signing is local ad-hoc signing, not notarized public distribution.
Clean-machine installation, real-controller reconnect, audible calibration and
long-session performance must pass before stable main promotion. Maintain the
feature → develop → stage → main path and runtime-specific build evidence.
