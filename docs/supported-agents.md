MiniMax Code uses global skills and is opt-in: run `npm run openspec -- init --tools minimax-code` if you want to modify your user-level MiniMax setup.
Hermes needs this repo's `.hermes/skills` added to `skills.external_dirs` in its user configuration.
Some editor integrations need an editor restart. See the [upstream tool guide](https://github.com/Fission-AI/OpenSpec/blob/main/docs/supported-tools.md).

Workflow integrations are separate from constitution loading. See `governance/adapters.json` for the instruction files maintained here. For a tool without a native constitution adapter, explicitly attach `AGENTS.md`.
